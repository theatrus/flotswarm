# flotswarm Logo Concept

This branch uses the original image-model render as the README logo for review.
The PNG is transparent around the mark so it works on GitHub and dark surfaces.

![flotswarm logo concept](assets/flotswarm-logo.png)

## Prompt Summary

- Infrastructure logo for flotswarm.
- One ingress webhook/event fans out to per-host agents.
- Flotilla/wave motif plus swarm/network fan-out motif.
- Deep navy background, teal/cyan signal lines, warm amber ingress node.
- Vector-friendly, no insects, no nautical clip art, no generic cloud icon.
